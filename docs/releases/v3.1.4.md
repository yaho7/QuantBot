QuantBot 3.1.4 保留原有工作台、管理后台及原创图标，更新净值图表。

- 首页和策略详情的净值主图改用已有的 Lightweight Charts，提供渐变面积图、金融时间轴、右侧金额轴和十字线。
- 图表跟随明暗主题与配色，悬浮读数保留服务端的十进制文本；数据更新保留图表视图。
- 修复旧版表格样式对金融图表布局的影响。
- 保留最低八位密码、去掉 Required 标记、通知渠道无需自定义名称，以及隔离沙盒自动下发模拟命令的调整。

本版本提供 Linux amd64/arm64 二进制、SHA-256 校验文件及双架构 Docker 镜像。
使用现有 Compose 的用户可运行 `docker compose pull && docker compose up -d` 更新，并保留现有数据卷。
原生安装可运行 `bash install.sh --ref v3.1.4`。
