QuantBot 3.1.0 更新了工作台、策略接入和主机监控。

- **工作台**：采用 Astryx 控件，统一明暗布局和页面间距。Classical 提供多种配色；桌面和手机布局分别保存，组件支持拖动、缩放和展开。图表显示坐标轴和数据点读数。
- **策略接入**：创建策略后，从同一弹窗查看 Endpoint、Key 和 Token、重新生成 Token，或复制 AI 接入提示词。共享沙盒测试是默认入口，可手动开启，默认有效 60 分钟。Python、JavaScript、Go 和 curl 示例读取本地 `quantbot.json`。
- **主机监控**：从 Agent 上报自动发现主机，按名称汇总最新数据。CPU、可用内存和进程用量可用于参考估算容量；上报中断后恢复时重新开始曲线。
- **部署**：单容器 Compose 直接挂载 `./data:/data`，默认只在本机开放 8888。Linux amd64 和 arm64 提供镜像、原生二进制及 SHA-256 校验文件。

从 3.0 升级时保留现有数据目录，并在更改卷挂载前备份。外观统一为 Classical，旧的上传主题不再启用。重新生成 Agent Token 会立即撤销旧 Token 和会话；更新该策略本地的 `quantbot.json` 后再连接。
