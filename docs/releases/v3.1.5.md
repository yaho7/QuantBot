QuantBot 3.1.5 重做监控工作台与管理后台，采用 shadcn/ui Lyra 的黑白主题和 Tailwind CSS 4。

- 工作台将导航收进同一顶栏，净值主图占整行，策略状态和待处理事项分区显示。手机端空间不足时，导航自动只显示图标。
- 净值、指标和 K 线统一使用 shadcn Chart 与 Recharts。图表读数保留上报的十进制文本，时间范围支持鼠标和键盘操作。
- 主机、操作记录和告警归入管理后台的「监控」分组。近期告警角标在工作台后台入口、后台的「告警」项和手机后台顶栏持续显示。
- 策略页通过一个下拉菜单切换卡片与列表。组件区按屏幕宽度自动加载保存的布局。品牌标志去掉外框，工作台直接打开当前启用的主题。
- 提供可选 Lyra 2.0.1 主题包。主题在隔离页面中运行，控制命令仍由主程序处理权限检查、确认和回执。

本版本提供 Linux amd64/arm64 二进制、SHA-256 校验文件、双架构容器镜像和 `lyra-theme.zip`。
使用现有 Compose 的用户可运行 `docker compose pull && docker compose up -d` 更新。原生安装可运行 `bash install.sh --ref v3.1.5`。
