QuantBot 3.1.3 启用完整 Astryx 新版界面，覆盖监控工作台、策略详情、动态控制、管理后台和登录初始化。

- 使用统一的 Astryx 导航、组件、排版及主题，支持桌面和手机的明暗界面。
- 工作台提供状态总览、四种策略视图、账户图表和自定义布局；管理后台保持独立布局。
- 继续使用用户原创 QuantBot 图标。
- 保留最低八位密码、去掉 Required 标记、通知渠道无需自定义名称，以及隔离沙盒自动下发模拟命令的调整。
- 保留命令权限、确认、执行许可和真实回执流程。第三方主题仍与管理后台隔离。

本版本提供 Linux amd64/arm64 二进制、SHA-256 校验文件及双架构 Docker 镜像。
使用现有 Compose 的用户可运行 `docker compose pull && docker compose up -d` 更新，并保留现有数据卷。
原生安装可运行 `bash install.sh --ref v3.1.3`。
