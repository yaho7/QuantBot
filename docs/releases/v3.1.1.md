QuantBot 3.1.1 修复了自托管服务通过反代访问时返回 `untrusted_origin` 的问题。

- 移除公网域名和 HTTPS 的入口限制。内网 HTTP 和 HTTPS 反代都可直接使用，Compose 不需要配置公网域名或允许代理列表。
- 登录、Agent Token 和浏览器同源操作检查继续生效。反代提供的原始 Host 和协议用于生成正确的 API 地址。
- Python、JavaScript、Go 和 curl 的 `quantbot.json` 示例同时支持 HTTP 和 HTTPS。

使用现有 Compose 的用户可以运行 `docker compose pull && docker compose up -d` 更新。
