QuantBot 3.1.2 沿用原有工作台、管理布局及自制标识，改进账户设置和接入验证。

- 初始化管理员和修改密码时，最低密码长度调整为 8 位。
- 去掉表单的 Required 标记；通知渠道直接使用渠道类型，无需填写自定义名称。
- 沙盒在无输入模拟动作及其可用状态上报后，自动下发一条测试命令。Agent 仍须轮询、领取执行许可并提交真实测试回执，无需在页面点击下发。
- 重复上报、轮询和重连不会重复创建该沙盒命令；自动验证仅使用隔离的沙盒数据，正式策略仍保留原有权限及确认流程。
- 保留工作台参数展示、策略详情和桌面/手机独立布局。

本版本提供 Linux amd64/arm64 二进制、SHA-256 校验文件及双架构 Docker 镜像。
使用现有 Compose 的用户可运行 `docker compose pull && docker compose up -d` 更新，并保留现有数据卷。
原生安装可运行 `bash install.sh --ref v3.1.2`。
